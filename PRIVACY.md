# Privacy Policy

This plugin forwards prompts, model parameters, and the API key configured in Dify to the EmpirioLabs API at `https://api.empiriolabs.ai` so it can return model responses.

The plugin itself does not store prompts, completions, files, or credentials. Credentials are stored by the Dify instance and sent to EmpirioLabs only as an authorization header during model requests.

For EmpirioLabs data handling practices, see https://empiriolabs.ai/.
