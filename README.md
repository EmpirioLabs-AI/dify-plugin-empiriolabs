# EmpirioLabs AI

[EmpirioLabs AI](https://empiriolabs.ai/) provides an OpenAI-compatible API for text, image, video, audio, search, and 3D models through one endpoint:

```text
https://api.empiriolabs.ai/v1
```

This plugin lets Dify use EmpirioLabs AI as a model provider for LLM nodes, agents, and workflows.

## Configure

1. Create an EmpirioLabs account and API key.
2. Install this plugin in Dify.
3. Go to **Settings > Model Provider > EmpirioLabs AI**.
4. Enter your EmpirioLabs API key.
5. Select one of the predefined models or add any model from the catalog as a customizable model.

## Models

The plugin includes a small set of predefined chat models:

- `qwen3-7-max`
- `deepseek-v4-pro`
- `kimi-k2-7-code`

For the full current catalog, see [EmpirioLabs models](https://empiriolabs.ai/models) or the [model docs](https://docs.empiriolabs.ai/models).
